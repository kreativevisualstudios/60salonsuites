60 SALON SUITES — GITHUB PAGES PACKAGE

Files to upload: upload the CONTENTS of this folder to the ROOT of your GitHub repository.
Do not upload the ZIP itself as the only file.

Main page: index.html
Suites directory: suite-directory.html (standalone HTML; Instagram-only social links)
Locations: locations.html (Brandon, Florida)
Privacy: privacy.html
Photos/Copyrights: copyrights.html
Shared styles and scripts for main site: styles.css, script.js
Assets: assets/

To publish: GitHub repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
This package does not configure the custom domain or DNS. Test the GitHub Pages preview before connecting the official domain.
